# FX5-Q Converter

Mitsubishi FX5 계열과 Q 계열 프로젝트의 래더 텍스트와 코멘트를 검토하고, 반대 계열의 GX 가져오기용 CSV 후보를 만드는 Windows 앱입니다. 앱의 표시 이름은 Q-FX Converter입니다.

## 다운로드와 실행

[Releases](https://github.com/plcmanjp/fx5-q-converter/releases)에서 `Q-FX-Converter-v버전.zip`을 내려받아 **전체 압축을 풀고** `Q-FX-Converter.exe`를 실행합니다. EXE만 옮기면 실행되지 않습니다. Windows x64용이며 코드 서명은 제공하지 않습니다.

파일 등록, 주소 규칙, 결과의 3개 화면을 사용합니다. 원본을 고르고 대상 CPU 및 필요한 주소 규칙을 설정한 뒤 변환합니다. 기존 파일을 덮어쓰지 않고 새 결과 폴더에 저장합니다. 현장 전용 자동 매핑 프로필은 포함하지 않습니다.

분석에 실패하면 창 중앙에 원인과 다음 조치를 표시합니다. **오류 상세 보기**로 다시 열거나 **전체 복사**로 상세를 복사할 수 있습니다. 미해독 프로그램이 있는 원본은 변환을 중단하며, 파일이 변경된 경우와 판독 지원이 부족한 경우를 구분합니다.

## 업데이트

실행 후 GitHub의 최신 정식 Release를 백그라운드에서 한 번 조회합니다. 새 버전이 있으면 앱 창 중앙에서 알리고, 우측 상단 **업데이트 확인**으로 직접 확인할 수도 있습니다. 조회 실패가 변환을 막지는 않습니다. 사용자 선택으로 Release 페이지를 열며 파일 다운로드, 교체와 설치는 자동 수행하지 않습니다.

조회 대상은 이 저장소로 고정되어 있습니다. 원본 프로젝트, 주소 규칙, 파일 경로나 변환 결과는 전송하지 않습니다. GitHub 연결에는 일반적인 네트워크 연결 정보가 전달됩니다. 미리보기 Release와 다운로드 ZIP이 준비되지 않은 Release는 새 정식 버전으로 알리지 않습니다.

## 공개 범위

이 저장소가 앱 소스, 빌드 도구, 공개 문서와 Release의 정본입니다. 공개 기능은 이 저장소에서 개발하고 검증합니다. 현장 원본, 비공개 개발 자료, 검증 근거와 현장 전용 프로필은 별도의 비공개 작업공간에서 관리합니다. 비공개 수락 기준 사본을 이 저장소에 덮어쓰거나 해당 작업공간의 Git 이력을 가져오지 않습니다.

공개 런타임은 비공개 검증 원본 대신 빌드 전에 검증해 추출한 고정 규칙 데이터를 사용합니다. 이 데이터의 무결성 확인은 GX 프로그램의 실제 실행 검증을 대신하지 않습니다. 지원하지 않는 내용은 원문과 사유를 남기며 검토가 필요한 결과를 정상 운전 보증으로 표시하지 않습니다.

현장 원본과 결속된 코멘트 보정, 자동 치환, 복구 예외는 공개판에 없습니다. 일반 구조 해석으로 확정할 수 없는 복구 결과는 정상 가져오기 후보로 승격하지 않습니다. 사용자가 주소 규칙을 직접 설정하는 일반 변환을 제공합니다.

생성된 파일은 실제 GX 가져오기, CPU 및 모듈 구성, 주소 배정과 현장 동작 검증이 필요합니다. 이 앱은 PLC에 접속하거나 다운로드하지 않습니다. Mitsubishi Electric의 공식 제품이 아닙니다.

## 소스 실행과 빌드

[빌드 안내](BUILD.md)를 따릅니다. 배포 소스만으로 실행 및 빌드할 수 있으며 비공개 저장소나 현장 원본을 요구하지 않습니다. 공개 parser는 검증된 고정 wheel을 포함하고 네트워크 최신판으로 자동 교체하지 않습니다.
