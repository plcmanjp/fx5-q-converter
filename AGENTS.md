# Canonical application source

This independent repository is the editable source of truth for the converter,
public build tools, documentation and Releases. Develop public features here.
Never import a private workspace's history, source snapshot, site profiles,
customer projects, raw validation material or credentials.

Private consumers own their original inputs, acceptance evidence and pinned
copies. A private pin is not a parallel implementation or permission to replace
this repository with a private export. Adopt source and artifacts explicitly;
do not silently synchronize a consumer to the latest checkout.

Keep this repository independently cloneable and buildable without private
paths. Preserve fixed reader dependencies and fail-closed conversion behavior.
Run relevant tests before committing. Do not connect to PLCs or run engineering
software. Release publication needs explicit user authorization.

Keep the public source manifest consistent with its committed files, excluding
the manifest itself. Preserve existing tags and released asset bytes. Store
disposable build/test work outside this checkout and OneDrive. Never force push
or delete another session's work.
